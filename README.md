# Asopalav Greens — Luxury Banquet & Party Plot

Editorial luxury wedding estate, sprawling manicured grounds, and pillarless crystal banquet hall in Vadodara, Gujarat. Built with React 19, Vite, Tailwind CSS v4, and GSAP.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+ or v20+ recommended)
- `npm` (bundled with Node.js)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
The site will start at: `http://localhost:3000`

### 3. Production Build
```bash
npm run build
npm run preview
```

### Available Scripts
- `npm run dev`: Launches Vite development server on port 3000
- `npm run build`: Bundles the application for production to `dist/`
- `npm run preview`: Previews the production build locally
- `npm run lint`: Type-checks TypeScript files using `tsc --noEmit`
